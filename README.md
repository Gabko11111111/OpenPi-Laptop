# OpenPi-Laptop
OpenPi Laptop

OpenPi Laptop is a small, modular laptop built around a Raspberry Pi 5.
The project will have a touchscreen display, a USB keyboard, microSD storage,
and a custom 3D-printed case.

## Goals

- Boot Raspberry Pi OS reliably.
- Show the desktop on the built-in display.
- Support typing with a USB keyboard.
- Keep the Raspberry Pi cool inside the case.
- Make the case easy to open, repair, and improve.

## Planned hardware

See [BOM.csv](BOM.csv) for the complete parts list.

- Raspberry Pi 5, 4 GB RAM
- 64 GB microSD card
- Raspberry Pi Touch Display 2, 7-inch
- Official Raspberry Pi 27 W USB-C power supply
- Active Cooler for Raspberry Pi 5
- Small USB keyboard
- Custom PETG 3D-printed case

## Build plan

1. Test the Raspberry Pi, display, storage, power supply, and keyboard outside the case.
2. Install Raspberry Pi OS on the microSD card.
3. Measure the real parts and design the case.
4. Print a small test piece before printing the complete case.
5. Assemble the laptop and check cooling, cables, and hinges.
6. Record a video of the finished laptop working.

## Safety

The first version will use wall power. A battery will only be added later with
a proper battery-management and power-conversion module. The Raspberry Pi must
be powered by a suitable 27 W USB-C supply and must have ventilation.
